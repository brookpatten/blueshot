Here are some details about blueshot that might be handy for silent/mass installations.
The information in this text file is only for blueshot versions 0.8.1 (build >=760)

INSTALLER
The blueshot installer is made with Inno Setup, see http://www.jrsoftware.org/isinfo.php
For command line options of the installer see: http://www.jrsoftware.org/ishelp/index.php?topic=setupcmdline
Additionally some blueshot options can also be passed to the installer, these are the /norun and /configure options.
Passed to the installer these work exactly like using them with the blueshot.exe when installed!

Important facts to the installer:
1) When doing a normal installation and blueshot is running the installer will show this, blueshot needs to be terminated.
2) When doing a silent installation and blueshot is running the installer will kill blueshot itself.
3) Installations where configure options are passed will only work for the user that started the installation!
	Work is being done to fix this in a newer blueshot but this is currently a limitation.
4) Installations done as Admin will be available to all users. (configure options will not!)
	This is also for the "Start blueshot with Windows start", when installing as Admin this is for all users!


blueshot Configuration

blueshot has a blueshot.ini file for the configuration, you can change this file at any time and blueshot will reload the settings.


blueshot commandline options:

        /help
                This help

        /exit
                Try to close all running instances, could be used for installers

        /openfile [filename]
                Open the bitmap file in the running blueshot instance or start a new instance
				
		/norun
				Use as last option if you don't want the started executable to spawn a blueshot instance.
				e.g. when you only want to change settings but don't want to have a running blueshot afterwards.
